# Security

Please report vulnerabilities privately through GitHub's "Report a vulnerability" (security
advisories) on this repository, not in a public issue. Include steps to reproduce.

Never test with real participants' information or against a deployment that holds it. Run
Heartbeat locally (`npm run dev`) with a host in setup (training) mode and made-up participants.

The security model is described in [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md#security-model).
